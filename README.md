# Math Puzzle (Sliding Puzzle) σε JavaFX

Παιχνίδι ολίσθησης πλακιδίων 3×3 (8 Puzzle) και 4×4 (15 Puzzle).

## Απαιτήσεις

- Java 17 ή νεότερη (JDK)
- Maven 3.6 ή νεότερο

Το JavaFX κατεβαίνει αυτόματα από το Maven.

## Εκτέλεση

```
mvn javafx:run
```

## Πώς παίζεται

- Πατήστε ένα πλακίδιο που είναι δίπλα (πάνω, κάτω, αριστερά, δεξιά) στο κενό για να μετακινηθεί.
- Στόχος είναι να μπουν τα πλακίδια στη σειρά 1, 2, 3, ... και το κενό στο τέλος.
- Το κουμπί «Νέο Παιχνίδι / Shuffle» ανακατεύει ξανά.
- Από το αναπτυσσόμενο μενού επιλέγετε 3×3 ή 4×4.
- Εμφανίζονται ο αριθμός κινήσεων και ο χρόνος.

## Δομή

- `src/main/java/jay/PuzzleModel.java`: ο πίνακας, η κίνηση, το ανακάτεμα και ο έλεγχος νίκης
- `src/main/java/jay/PuzzleApp.java`: το γραφικό περιβάλλον (JavaFX)
- `docs/screenshots/`: στιγμιότυπα οθόνης

# Εργασίες και Βαθμολογίες (Python)

Εφαρμογή με tkinter και sqlite3 για βαθμούς και εργασίες (pdf) φοιτητών. Ο κώδικας είναι στο `grades_app/app.py`.

## Εκτέλεση

Χρειάζεται Python 3 με tkinter (στο Ubuntu: `sudo apt install python3-tk`).

```
python3 grades_app/app.py
```

## Τι κάνει

- 5 μαθήματα, 3 βαθμοί για το καθένα (από 0 έως 10, δέχεται και κόμμα).
- Βγάζει τον Μ.Ο. κάθε μαθήματος. Αν είναι >= 5 δείχνει μήνυμα επιτυχίας, αλλιώς αποτυχίας.
- Το κουμπί «Εμφάνιση βαθμολογιών» δείχνει όλους τους βαθμούς του φοιτητή σε πίνακα.
- Το «Ανέβασμα εργασίας» αντιγράφει ένα pdf στον υπολογιστή και το «Άνοιγμα εργασίας» το ανοίγει.

## Πού αποθηκεύονται

Στον φάκελο `~/vathmoi`: η βάση `vathmoi.db` (sqlite) και ο φάκελος `pdf` με τις εργασίες.
