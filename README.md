# Math Puzzle (Sliding Puzzle) σε JavaFX

Παιχνίδι ολίσθησης πλακιδίων 3×3 (8 Puzzle) και 4×4 (15 Puzzle).

## Απαιτήσεις

- Java 17 ή νεότερη (JDK)
- Maven 3.6 ή νεότερο

Το JavaFX κατεβαίνει αυτόματα από το Maven.

## Εκτέλεση

```
mvn javafx:run
```

## Πώς παίζεται

- Πατήστε ένα πλακίδιο που είναι δίπλα (πάνω, κάτω, αριστερά, δεξιά) στο κενό για να μετακινηθεί.
- Στόχος είναι να μπουν τα πλακίδια στη σειρά 1, 2, 3, ... και το κενό στο τέλος.
- Το κουμπί «Νέο Παιχνίδι / Shuffle» ανακατεύει ξανά.
- Από το αναπτυσσόμενο μενού επιλέγετε 3×3 ή 4×4.
- Εμφανίζονται ο αριθμός κινήσεων και ο χρόνος.
