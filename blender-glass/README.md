# Κρυστάλλινο ποτήρι στο Blender

Εργασία: τρισδιάστατο ποτήρι κρασιού.

- `01_model.py` -> `glass_model.blend` (μόνο το σχήμα, χωρίς υλικά)
- `02_scene.py` -> `glass_scene.blend` (υλικό γυαλιού + φώτα + κάμερα)
- `03_render.py` -> `glass_render.png` (τελικό render, 2000x2500, Cycles)

Τρέχουν με το πακέτο `bpy` (pip install bpy), με τη σειρά:

```
python 01_model.py
python 02_scene.py
python 03_render.py
```
